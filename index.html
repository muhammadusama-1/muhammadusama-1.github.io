Number Field Sieve and Quadratic Sieve

Python · SageMath · Integer Factorization

As part of my master's thesis at LUMS, under the supervision of Peter Stevenhagen, I studied and implemented the Number Field Sieve (NFS) and the Quadratic Sieve (QS), two algorithms for integer factorization.

The project covers the mathematical ideas behind polynomial selection, sieving, collecting smooth relations, linear algebra, and the square-root step used in the factorization process.

I implemented these algorithms using Python and SageMath. The repository contains the code for the project.
